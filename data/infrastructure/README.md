# 인프라 원본 데이터

## `bus-stops.csv`

- 출처: [서울시 버스정류소 위치정보](https://data.seoul.go.kr/dataList/OA-15067/S/1/datasetView.do)
- 원본: `서울시버스정류소위치정보(20260902).xlsx`
- 기준일: 2026-09-02
- 저작권자: 서울특별시
- 이용허락: 공공누리 제1유형(출처표시, 상업적 이용·변경 가능)

원본의 `NODE_ID`, `Y좌표`, `X좌표`를 각각 `stop_id`, `latitude`, `longitude`로 바꾸고 다른 열은 제거한 UTF-8 CSV다. 총 11,236건이며 `stop_id`는 중복이 없고 좌표 결측이 없다.

원본을 갱신할 때는 동일한 열 매핑을 유지하고, 행 수·ID 중복·결측·WGS84 범위를 다시 검증한다.
