# 서울 매물 주변 센서 소음 지표 수집 명세

## 승인된 범위 (2026-09-18)

- 서울 S-DoT 환경정보와 공식 센서 설치 위치를 사용한다.
- 서울 매물 등록 후 500m 이내 가장 가까운 센서를 선택한다. 경계 500m를 포함한다.
- 최근 7일 유효 관측값을 요약하며 점수 산식은 추천 단계에서 처리한다.
- 서울 시간 기준 오늘 00:00을 종료 경계로 하여 직전 완료된 7일을 사용한다. 시작 포함, 종료 제외.
- 시간별 `AVG_NIS`의 산술평균을 사용하고, 서로 다른 유효 관측 시간 84개 이상이어야 저장한다.
- 최근접 센서가 결측이면 더 먼 센서로 바꾸지 않고 미수집 처리한다.
- 기존 `property_feature`에 `NOISE` 지표만 저장한다. 원자료용 테이블을 추가하지 않는다.
- 소음 요약값(dB), 센서 거리(m), 센서 ID, 관측기간, 유효 관측 건수를 함께 보관한다.
- 센서 부재, 조회 실패, 유효 관측 부족 시 새로운 소음값을 저장하지 않는다. 0으로 대체하지 않는다.
- 매물 등록과 치안 수집 성공값을 유지한다. 소음 재수집 실패 시 이전 성공값을 유지한다.
- 주변 센서의 환경소음 관측 요약으로 표시한다. 실내·층간소음, 방음 성능, 법정 등가소음도라고 표시하지 않는다.

## 구현 계약과 미확인 연결 사항

사용자가 기간·평균·최소 관측량·결측 정책을 승인했다. 아래 세부 규칙은 초기 구현의 보수적 품질 처리이며 원본 보존 원칙을 유지한다.

1. 비숫자·빈 값·0·음수·무한값은 유효 평균으로 사용하지 않는다. 0은 결측 sentinel로 확정한 것이 아니라 유효성 미검증으로 제외한다.
2. 같은 센서·같은 시간의 동일 값은 한 건이다. 서로 다른 유효 값이 충돌한 시간은 제외한다.
3. 센서 교체 전 ID를 현재 ID로 자동 합치지 않는다. 거리 동률이면 현재 센서 ID 사전순으로 선택한다.
4. 수치 평균은 소수점 6자리 HALF_UP. 센서 대표성이나 방음 성능을 보장하지 않는다.
5. `NOISE` category의 6개 지표를 하나의 트랜잭션으로 갱신한다:
   - `SENSOR_AVG_NOISE_7D`: numeric_value, dB
   - `SENSOR_DISTANCE`: numeric_value, m
   - `SENSOR_ID`: text_value, unit 없음
   - `OBSERVATION_START`·`OBSERVATION_END`: text_value, 서울 로컬 ISO 날짜시간. 종료 제외.
   - `VALID_HOUR_COUNT_7D`: numeric_value, hour
6. API는 자치구별로 1,000건씩 전량 페이지 수집하고 결과를 1시간 캐시한다. 연결·읽기 제한시간은 각각 3초·10초다.
7. 서울시가 안내하는 API 주소는 HTTP 8088이다. HTTPS 8088은 TLS 오류, HTTPS 443은 연결 시간초과가 발생했다.
   실제 인증키 호출은 성공했지만 전송 구간 암호화가 되지 않으므로 이 연결은 보안상 제약이 있다.
