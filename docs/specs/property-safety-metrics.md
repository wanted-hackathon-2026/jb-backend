# 서울 매물 치안 지표 수집 명세

## 승인된 기능 계약

### CSV 연결 및 좌표 제외 (2026-09-18 승인 반영)

- 원본 파일은 변경하지 않는다. CP949 CSV의 관리번호로 중복을 검사하고, 같은 좌표의 다른 관리번호는 유지한다.
- CCTV는 카메라대수를 합산하고 비상벨은 행당 1개로 집계한다. 첨부 파일의 WGS84위도/WGS84경도를 사용한다.
- 누락·숫자 변환 불가·위경도 유효 범위 초과·서울 행정경계 밖 좌표는 제외하고 종류별 제외 건수를 로그로 기록한다.
- 행정경계는 WGS84 Polygon/MultiPolygon GeoJSON을 사용한다. 사각형 판정으로 대체하지 않는다. 경계선은 포함한다.
- 파출소는 시도청=서울청만 선택하며 기존 GeocodingClient로 주소를 변환한다. 변환 실패는 전체 거리 지표 실패로 처리하여 일부 관서만으로 최단거리를 확정하지 않는다.
- 보안등 원자료가 없는 동안 해당 지표는 생성하지 않는다. 파일 없음/파싱 실패/잘못된 수량/중복 관리번호는 수집 실패이며 0으로 저장하지 않는다.
- 로컬 파일은 data/safety에 두며 cctv.csv가 있으면 자동 연결한다. 배포 서버에는 별도 파일 배치가 필요하다.
- 성공적으로 읽은 시설 목록은 프로세스 내 캐시로 재사용한다. 파일 변경 반영은 재시작 시 수행한다. 실패한 읽기는 캐시에 넣지 않는다.
- 현재 등록 후 동기 호출을 유지한다. 첫 파출소 수집은 여러 외부 호출로 오래 걸릴 수 있다. 비동기·자동 갱신·재시도 정책은 별도 작업이다.
- 경계 자료의 기준 연도와 출처는 로컬 설정 문서에 명시한다. 최신 경계와 일치 여부를 확인하지 못한 자료를 최신이라고 표시하지 않는다.

- 서울 매물 등록 후 치안 데이터를 자동 조회·집계하여 기존 property_feature에 저장한다.
- 전국 원자료 적재 테이블과 새 DB 테이블은 추가하지 않는다.
- 점수 산식은 제외한다. 외부 파일은 필요 지역을 추출해 캐시할 수 있다.
- 기존 관리자 권한 및 가입 완료 인가, 매물 등록 요청·201 응답 계약은 유지한다.
- 서울 이외 매물의 기존 등록 동작은 유지하며 이번 치안 수집만 실행하지 않는다.

| category | metric_code | 의미 | unit |
| --- | --- | --- | --- |
| SAFETY | CCTV_COUNT_500M | 직선거리 500m 이내 카메라 대수 합계(설치 위치 행 수가 아님) | count |
| SAFETY | EMERGENCY_BELL_COUNT_500M | 직선거리 500m 이내 비상벨 개수 | count |
| SAFETY | SECURITY_LIGHT_COUNT_500M | 직선거리 500m 이내 보안등 설치 개수 합계 | count |
| SAFETY | NEAREST_POLICE_STATION_DISTANCE | 서울 내 최근접 지구대·파출소까지 직선거리 | m |

- 정확히 500m인 시설도 포함한다. 최초 반경은 500m이다.
- numeric_value에 결과를, computed_at에 계산 시각을 저장한다.
- 동일 property_id/category/metric_code 재수집은 갱신한다. 중복 행을 생성하지 않는다.
- 수집이 완전하게 성공하고 주변 시설이 없을 때만 개수 0을 저장한다.
- 수집 실패, 불완전한 페이지/파일, 누락된 필수 좌표·수량은 정상적인 0과 구분한다.
- 실패한 지표는 새로 저장하지 않고 기존 정상 지표가 있으면 유지한다.
- 서울 파출소 원자료에 시설이 없으면 거리 0을 저장하지 않는다.
- 일부 수집 실패로 이미 저장한 매물을 롤백하거나 성공 지표를 삭제하지 않는다.
- 인증키는 지표, 원자료 캐시, 로그, 응답에 노출하지 않는다.

## 제공처 확인 내용 및 미완료 항목

- CCTV: https://www.data.go.kr/data/15013094/standard.do (파일 제공)
- 비상벨: https://www.data.go.kr/data/15028206/standard.do (파일 제공, 좌표계 주의)
- 보안등: https://www.data.go.kr/data/15017320/standard.do (파일/API)
- 지구대·파출소: https://www.data.go.kr/data/15077036/fileData.do (주소 자료)
- 첨부 CCTV/비상벨/파출소 CSV를 확인했다. 인코딩은 CP949이며 CCTV/비상벨 파일은 WGS84위도/WGS84경도 컬럼을 제공한다.
- 비상벨 공식 설명의 EPSG:5174 안내와 별개로 첨부 파일의 명시된 WGS84 컬럼을 사용한다. 일부 잘못된 좌표는 승인된 제외 기준을 적용한다.
- 파출소 주소는 좌표 변환이 필요할 수 있다. 전국 파일에서 서울만 선택한다.
- 수집 실행 방식(동기/비동기), 제한시간, 재시도 및 캐시 갱신 주기는 아직 미확정이며 조용히 구현값으로 고정하지 않는다.
- 서울 경계 밖 시설은 제외하도록 사용자 승인되었다. 실제 폴리곤 경계 검사를 적용한다.

## 테스트 단계

1. 초기 계산 계약: 대수 합계, 비상벨 수, 500m 경계 포함, 최근접 거리, 빈 입력.
2. 제공처 계약: 서울 필터, 실제 필드·좌표계·누락·중복·전체 페이지 검증.
3. 등록 및 DB 계약: 자동 실행, 성공 지표 저장, 실패 시 매물 유지, 독립 지표 성공, 재수집 갱신.

구현 결과에 맞춰 기대값을 변경하지 않는다. 미확정 정책은 사용자 결정 후 명세에 반영한다.

## 구현 현황 (실데이터 연동 완료 아님)

- 초기 계산 테스트 6개는 RED 확인 후 구현하여 통과했다.
- 기존 property_feature JPA 매핑과 원자적 upsert를 추가했다. DB 테이블 및 스키마 변경은 없다.
- 매물 등록 커밋 후 지표 수집 서비스가 실행된다. 서울 여부는 sggCode의 11 접두사로 제한한다.
- 각 지표의 외부 읽기는 DB 저장 트랜잭션 밖에서 실행하며 저장 실패는 다른 지표와 분리된다.
- 수집 소스 계약은 완전한 서울/WGS84 시설 목록을 반환하거나 실패해야 한다. 테스트에서는 제어된 소스를 주입한다.
- CsvSafetyFacilitySource를 추가했다. 로컬 파일 배치 시 실제 CCTV/비상벨 자료를 읽고 서울 경계로 필터링한다.
- 로컬 자료를 별도 data/safety에 준비했다. 원본과 인증키 파일은 변경하지 않았다. 원자료는 Git 및 앱 패키지에서 제외한다.
- 파출소 주소 변환 코드가 연결되었지만 실제 VWorld 인증키를 사용한 변환은 미검증이다. 보안등 원자료는 미확보이다.
- 현재 동기 호출은 유지한다. 첫 파출소 변환의 응답 지연이 있어 운영 전 사전 변환/비동기 정책 확정이 필요하다.
- 최신 서울 경계 검증과 실제 백엔드 재시작·수동 로그인 등록·배포는 별도이다. 코드 테스트 통과를 실서비스 검증으로 보고하지 않는다.
