# 서울 매물 주변 인프라 지표 수집 명세

## 승인된 범위 (2026-09-19)

- 서울 매물 등록 후 주변 인프라 원자료 값을 자동 수집한다.
- 지하철역은 가장 가까운 역까지의 직선거리를 저장한다.
- 버스정류장과 편의점은 직선거리 500m 이내 개수를 저장한다. 정확히 500m인 시설을 포함한다.
- 대형마트·병원·약국은 직선거리 1km 이내 개수를 각각 저장한다. 정확히 1km인 시설을 포함한다.
- 점수 산식과 가중치는 추천 단계에서 처리하며 이 기능에서는 계산하지 않는다.
- 시설 원본용 테이블을 추가하지 않고 기존 `property_feature`에 요약값만 저장한다.
- 외부 자료 조회 실패는 매물·치안·소음 저장을 롤백시키지 않는다.
- 6개 지표는 각각 독립적으로 저장한다. 한 항목이 실패해도 성공한 다른 항목은 저장한다.
- 성공한 전체 조회의 0개와 실패·불완전 조회를 구분한다. 실패를 0으로 대체하지 않는다.

## 저장 계약

| category | metric_code | numeric_value | unit |
| --- | --- | --- | --- |
| INFRASTRUCTURE | NEAREST_SUBWAY_STATION_DISTANCE | 최근접 지하철역 직선거리 | m |
| INFRASTRUCTURE | BUS_STOP_COUNT_500M | 500m 이내 버스정류장 개수 | count |
| INFRASTRUCTURE | CONVENIENCE_STORE_COUNT_500M | 500m 이내 편의점 개수 | count |
| INFRASTRUCTURE | LARGE_MART_COUNT_1KM | 1km 이내 대형마트 개수 | count |
| INFRASTRUCTURE | HOSPITAL_COUNT_1KM | 1km 이내 병원 개수 | count |
| INFRASTRUCTURE | PHARMACY_COUNT_1KM | 1km 이내 약국 개수 | count |

- 거리는 매물과 시설의 WGS84 좌표를 사용한 구면 직선거리다. 도로·보행·대중교통 이동거리가 아니다.
- 동일 `property_id/category/metric_code`를 재수집하면 기존 행을 갱신하고 중복 행을 만들지 않는다.
- `computed_at`은 각 지표가 성공적으로 계산된 UTC 시각을 저장한다.
- 재수집에서 특정 지표가 실패하면 그 지표의 기존 성공값을 유지하고, 성공한 다른 지표는 새 값으로 갱신한다.

## 승인된 데이터 품질 규칙 (2026-09-19)

1. 거리는 미터 단위 소수점 6자리 `HALF_UP`으로 저장하고 개수는 0 이상의 정수로 저장한다.
2. 동일 시설 ID는 한 번만 집계하고 ID가 없거나 WGS84 좌표가 잘못된 항목은 제외한다.
3. API가 전체 건수를 제공하면 실제 수신 건수와 대조한다. 전체 건수가 없는 API는 문서에 정의된 마지막 페이지까지 정상 수신했는지 확인한다. 불완전한 경우 해당 지표만 미수집 처리한다.

## 수집 계약

- 서울 매물에만 수집한다. `sggCode`가 `11`로 시작하지 않으면 매물만 등록하고 인프라 수집을 건너뛴다.
- 시설 유형은 제공처의 공식 카테고리 분류를 사용한다. 이름 키워드로 대형마트·병원 등을 임의 추정하지 않는다.
- 지하철역은 반경 내 개수가 아니라 서울 내 최근 역 하나의 거리를 구한다. 유효한 역이 하나도 없으면 수집 실패다.
- 반경 개수는 제공처의 완전한 조회 성공이 확인된 경우에만 저장한다.
- 외부 I/O는 DB 저장 트랜잭션 밖에서 수행한다.
- 제공처 장애·제한시간·인증 실패·응답 파싱 실패·불완전 페이지를 0건으로 저장하지 않는다. 해당 지표만 미수집 처리하고 다른 지표 수집은 계속한다.
- API 인증키를 Git·로그·예외 메시지·API 응답·`property_feature`에 노출하지 않는다.

## 명세 테스트 대상

1. 거리: 최근 지하철역 선택, 동률 결정, 잘못된 좌표 제외, 미터 단위 반올림.
2. 반경: 500m·1km 경계 포함, 반경 밖 제외, 중복 ID 한 번 집계.
3. 결측: 정상 0개 저장, 실패를 0으로 대체하지 않음, 전체 건수 불일치·마지막 페이지 미수신 거부.
4. 등록: 서울 관리자 매물 등록 후 6개 지표 저장, 비서울 미수집, 외부 I/O 중 DB 트랜잭션 미유지.
5. 독립성: 한 지표의 조회·DB 실패와 관계없이 성공 지표 저장, 재수집 실패 지표의 기존값만 유지.
6. 보안: 외부 API 실패 로그와 예외에 인증키 미포함.

## 현재 범위에서 제외

- 인프라 점수·가중치·등급·추천 순위 계산.
- 카페·음식점·공원·은행·문화시설 등 추가 카테고리.
- 시설 원본의 DB 적재, 시설 변경 이력, 주기적 자동 재수집.
- 도로·보행·대중교통 경로 거리와 실시간 도착 정보.
- 외부 API 제공처·인증·캐시·재시도·제한시간의 최종 선택. 이는 공식 문서와 실제 응답을 검증한 후 구현 명세에 추가한다.
